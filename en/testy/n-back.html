Why it matters

N-Back is one of the most well-regarded working memory tests in cognitive science. Unlike simply memorizing a sequence, you must constantly compare the current cue to the one you saw N steps back, continuously updating what you're holding in mind. This ability to "juggle" information in real time is key in fast, changing game situations.

What it measures

Working memory capacity under continuous load — the ability to simultaneously hold and update information, not just passively remember it.

Who it helps

Players in fast game situations who need to track several variables at once, and anyone wanting to train working memory and multitasking.

Rating scale

≥ 90%Exceptional working memory
80–89%Excellent working memory
65–79%Average working memory
< 65%Below average working memory

The test is based on the classic 2-Back task (Kirchner, 1958) — one of the most widely used tools in cognitive science for measuring working memory capacity. Healthy young adults average 80–90% accuracy on 2-Back — performance drops sharply at harder levels like 3-Back.
