Memorize the sequence of numbers and repeat it in the same order. How many digits can you handle?

Why it matters

Digit span is a classic measure of short-term working memory capacity — the ability to temporarily hold and process a sequence of information. This capacity underlies memorizing game combinations, signals, and tactical instructions expressed as numbers.

What it measures

Short-term memory capacity for sequential numeric information — how many digits you can memorize and repeat in the correct order.

Who it helps

Players who need to remember game combinations and signals, coaches assessing cognitive capacity, and anyone wanting to train working memory.

Rating scale

≥ 9 digitsExceptional memory
7–8 digitsExcellent memory
5–6 digitsAverage memory
< 5 digitsBelow average memory

The test is based on the classic Digit Span test (part of the Wechsler intelligence scales) — one of the oldest tools in psychology for measuring working memory. The average adult remembers 7±2 digits in the correct order (the so-called "magic number seven," Miller, 1956) — experienced individuals reach 9 or more.
